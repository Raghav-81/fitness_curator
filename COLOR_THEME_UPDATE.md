# 🎨 Hanuman-Inspired Saffron Color Theme

## Color Palette

The application now features a vibrant, Hanuman-inspired color scheme with saffron/orange tones throughout.

### Primary Colors
- **Saffron Primary**: `#ff6b35` - Main brand color
- **Saffron Secondary**: `#f7931e` - Secondary accent
- **Saffron Light**: `#ffa726` - Lighter accent
- **Saffron Lighter**: `#fff5e6` - Very light background
- **Saffron Pale**: `#ffe8cc` - Pale background
- **Border Light**: `#fed7aa` - Soft borders

### Accent Colors
- **Red Accent**: `#dc2626` - Delete/remove actions
- **Gold**: `#fbbf24` - Highlights and hover states
- **Green Success**: `#10b981` - Success indicators

### Neutral Colors
- **Text Dark**: `#1f2937` - Primary text
- **Text Medium**: `#4b5563` - Secondary text
- **White**: `#ffffff` - Backgrounds

## Design Philosophy

The new color scheme is inspired by **Lord Hanuman**, symbolizing:
- **Strength**: Bold saffron tones
- **Energy**: Vibrant orange gradients
- **Devotion**: Warm, welcoming colors
- **Power**: Strong contrast and shadows

## Color Usage Guide

### When to use each color:

**Saffron Primary (#ff6b35)**
- Primary actions
- Active states
- Icons
- Borders on hover

**Saffron Secondary (#f7931e)**
- Gradient end points
- Secondary highlights
- Hover state transitions

**Saffron Light (#ffa726)**
- Gradient highlights
- Bright accents
- Hover state ends

**Saffron Lighter (#fff5e6)**
- Backgrounds
- Subtle highlights
- Card backgrounds on hover

**Gold (#fbbf24)**
- Special highlights
- Hover state accents
- Duration badges

**Red Accent (#dc2626)**
- Delete/remove actions
- Destructive operations
- Error states
